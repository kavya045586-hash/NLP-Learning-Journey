# 🧹 NLP Text Cleaning & Preprocessing Libraries

---

## 🛠️ Libraries for Text Cleaning & Preprocessing

- **string (Python standard library)**  
  → Remove punctuation.

- **re (Regular Expressions)**  
  → Remove patterns like numbers, URLs, HTML tags.

- **NLTK (Natural Language Toolkit)**  
  - `stopwords` → Remove common words like “is”, “the”.  
  - `word_tokenize` → Split text into tokens.

- **TextBlob**  
  → Spelling correction, sentiment analysis.

- **emoji**  
  → Detect/remove emojis.

- **BeautifulSoup (bs4)**  
  → Remove HTML tags when scraping.

- **unicodedata**  
  → Normalize text, remove special characters.

---

## 📊 Libraries for Feature Extraction

- **scikit-learn**  
  - `CountVectorizer` → Bag of Words.  
  - `TfidfVectorizer` → TF‑IDF.
