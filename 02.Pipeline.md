## 🔄 Pipeline

### Step 1 – Gathering the Text / Getting the Data
- Use pre-built public datasets  
- Web scraping (when data is not available ready-made)  
- APIs (structured + legal way to get live data)  
- Manual collection / crowdsourcing  
- Use NLP tools to auto-generate data (data augmentation)  

### Step 2 – Text Cleaning
Preparing raw text for analysis by applying preprocessing steps.

---

## 🧹 Text Cleaning Steps

1. **Lowercasing**  
   Convert all text to lowercase.

2. **Remove Punctuation**  
   - Remove symbols like `.,!?@#$%^&*()`  
   - In ML context → punctuation doesn’t add meaning.  
   - In deep learning (BERT, GPT, T5) → punctuation can carry meaning, so usually kept.  

3. **Remove Numbers**  
   - Optional, depends on task.  
   - Example: “I bought 5 phones” → number may or may not be needed.  

4. **Remove URLs / Links**  
   - Common in social media data.  

5. **Remove HTML Tags**  
   - If scraping from web, remove `<div>`, `<p>`, etc.  

6. **Remove Emojis & Special Characters**  
   - Emojis might break vectorization if not handled.  

7. **Remove Stopwords**  
   - Common words like “is”, “the”, “was”, “and”, “in” don’t help in meaning.  

8. **(Optional) Spelling Correction**  
   - Fix spelling mistakes using TextBlob or similar libraries.
